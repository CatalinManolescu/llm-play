## Choosing a Runtime

- Choose **Ollama** for the simplest local model workflow.
- Choose **Open WebUI** when you want a browser-based interface.
- Choose **llama.cpp** when you need GGUF support, local control, or detailed performance tuning.
- Choose **vLLM** when you need a model-serving runtime and API-oriented deployment.

Start with the guide that matches your immediate goal. The setups can be used independently.
